# TouhouLittleMaid-Sophisticated
车万女仆(Touhou Little Maid)附属模组，让女仆可以装备精妙背包

## 📋 前置依赖
**必须同时安装：**

[车万女仆（Touhou Little Maid）](https://www.mcmod.cn/class/1796.html)

[精妙背包（Sophisticated Backpacks）](https://www.mcmod.cn/class/3739.html)

本模组为附属扩展，无法独立运行。

## 📖 模组简介
本附属模组打通车万女仆与精妙背包的交互，女仆最多可以装备**3个精妙背包**。
在女仆原有GUI面板新增独立的精妙背包标签页，提供搜索、排序、物品存取、一键打开原生精妙背包界面等功能；新增道具「女仆背包扣」，快捷打开精妙背包面板。
女仆拾取、使用物品拥有清晰的优先级逻辑，女仆原生背包与精妙背包可以同时生效，支持配置背包渲染，大幅拓展女仆存储能力。

## ✨ 核心功能
### 🎒 女仆装备精妙背包
- 女仆最多可同时装备 **3个精妙背包**，与女仆原生背包互不冲突，可以同时使用。
- 默认渲染女仆原生背包；可在精妙背包标签页自由选择要渲染哪一个已装备的精妙背包。

### 🖥️ 新增精妙背包独立标签页（女仆GUI内）
- 物品搜索、排序功能，快速定位背包内物品
- 直接向精妙背包取出、放入物品
- 一键打开精妙背包**原生原版GUI界面**，完整使用精妙背包全部升级功能（磁铁、过滤、压缩等）

### 📎 新增物品：女仆背包扣
- 手持女仆背包扣**右键女仆**，直接跳转到女仆的精妙背包标签页。
- 无需层层点击女仆主界面，快捷访问精妙背包。

### 🤖 AI拾取与存储逻辑
1. **物品存取优先级**：女仆自身物品栏 → 女仆原生背包 → 已装备的精妙背包
2. 当女仆原生背包已满，但精妙背包仍有空位时，女仆会自动将拾取到的物品存入精妙背包。

## 📌 使用流程
1. 安装全部前置模组与本附属。
2. 将精妙背包装备到女仆身上，最多装备3个。
3. 打开女仆GUI，切换到新增的「精妙背包」标签页，管理背包内物品、调整渲染设置。
4. 使用「女仆背包扣」右键女仆，可以直接打开精妙背包标签页。
5. 女仆工作拾取物品时，会按照优先级依次填充自身栏位、原生背包、精妙背包。
